### E8-L4-T1 — Write the cast-duration probe, two-sided against synthetic fixtures

Reads an asciicast v2 file's own event timestamps — never wall-clock, never the file's
mtime (`docs/lore.md` L-0009 is the same class of bug: a filesystem timestamp is blind
to what actually happened inside the recording) — and compares the final event's
timestamp against a bound passed on the command line.

**Files:** `docs/growth/scripts/check-cast-duration.mjs`,
`docs/growth/scripts/fixtures/cast-duration/{under-bound,over-bound}.cast`

**acc:** `node docs/growth/scripts/check-cast-duration.mjs
docs/growth/scripts/fixtures/cast-duration/under-bound.cast 20.0` (a synthetic
asciicast-v2 fixture whose final event timestamp is `19.9`) exits 0, printing the
measured duration; the same command against `over-bound.cast` (final event at `20.1`)
exits non-zero, naming the measured duration and the bound it exceeded — both fixtures
committed so the probe is proven both ways before it is ever pointed at a real cast.

**depends_on:** none — no binary required, buildable today. **verifies:** `dec-0010`
(the ≤20s bar is what makes the clip "no setup and no prior context").

### E8-L4-T2 — Write the no-audio-stream probe, two-sided against `ffprobe`-shaped fixtures

Wraps `ffprobe -show_streams -print_format json`, but the *test* of the wrapper's logic
does not require `ffmpeg` installed or a real video file — it runs the parsing logic
directly against two committed JSON fixtures shaped like `ffprobe`'s own output, one
with an `audio` stream entry and one without.

**Files:** `docs/growth/scripts/check-no-audio.mjs`,
`docs/growth/scripts/fixtures/ffprobe/{no-audio,with-audio}.json`

**acc:** `node docs/growth/scripts/check-no-audio.mjs --ffprobe-json
docs/growth/scripts/fixtures/ffprobe/no-audio.json` exits 0, reporting `0 audio
streams`; the same command against `with-audio.json` (one `{"codec_type": "audio", ...}`
entry among its `streams[]`) exits non-zero, naming the audio codec found. The real
invocation mode (`node check-no-audio.mjs <path-to-cut>`, which shells out to `ffprobe`
itself) is documented in the script's header but not required to pass in this task,
since no cut exists yet.

**depends_on:** none — no binary or ffmpeg required for the fixture-driven proof.
**verifies:** `dec-0010` (no narration needed is the demo's stated strength).

**Files:** `docs/growth/scripts/check-cast-drift.mjs`,
`docs/growth/scripts/fixtures/cast-drift/{matching,missing-line}.cast`

**acc:** `node docs/growth/scripts/check-cast-drift.mjs

binary.

**depends_on:** `E8-L3-T6` (its expected-line source; this task reuses it rather than
re-deriving a second copy of the §6 text). **verifies:** `dec-0010`.
