## Constraints that bind this lane

- **Module path:** `github.com/kazi-org/dira` (the repo is public at that path).
- **Command path stays stdlib-only.** Use stdlib `flag` or a hand-written
  subcommand switch. Not cobra, not urfave/cli, not kong, not viper. `dec-0001`
  justified Go on cold start; a framework in the hook latency path spends the entire
  benefit. If you believe a dependency is unavoidable, say so in your output with
  the specific stdlib gap — do not add it silently.
- **Do not scaffold future epics.** No empty `internal/ledger`, `internal/ui`, or
  `internal/check` packages "for later". An empty package is a lie about progress and
  `go vet` cannot tell you it is unused. E0-L2 creates `internal/ledger` when it
  needs it.
- **Subcommands at E0 are the skeleton only.** `--help`, `--version`, and enough of a
  registry that adding `log`/`why`/`brief` in E1 is a one-line registration. Do not
  implement ledger behaviour; a subcommand that prints "not implemented" and exits
  non-zero is honest, a subcommand that silently succeeds is the vacuous-stub failure
  mode kazi exists to catch.
- **Exit-code contract, set here and depended on later:** `0` success, `1` runtime
  error, `2` usage error. E2 needs hooks to fail open, so record the contract now
  even though no hook exists yet.

## Landmines already identified — do not re-derive these

- `go:embed` cannot reference files above the embedding package's own directory.
  E0-L2 will need `schema/entry.schema.json` embedded, and the cleanest answer is a
  `package schema` Go file **inside** `schema/`. Leave `schema/entry.schema.json`
  where it is; its `$id` is a public URL and moving it breaks external consumers.
- `go list -deps ./cmd/dira` reports build dependencies only, so a test-only
  dependency (E0-L2 needs a JSON Schema library and a YAML parser) does not violate
  the lane's dependency clause. Verify this holds for the layout you choose — if
  `cmd/dira` transitively imports the validator package, it will.
- The dev machine is `go1.26.2 darwin/amd64`. Pin a `go` directive in `go.mod` that
  CI and goreleaser can both honour, and let E0-L3 read the version **from
  `go.mod`** rather than restating it.
