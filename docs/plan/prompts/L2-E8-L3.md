## Absolutes

1. **Nothing outward-facing is published by an agent.** This lane produces files.
2. **No fake output.** The harness must never print a hand-written imitation of `dira`
   output. If the binary is absent it fails loudly with a named error and produces no cast
   — a harness that can fabricate a convincing recording is the worst possible artifact in
   this epic, because it would let a launch ship a clip of software that does not work.
3. **No virality claims** anywhere in the assets or their READMEs.

**Two constraints that decide whether this fixture is honest:**

- **Share it with E3.** If E3's lane authors its own `dec-0060` fixture, the marketing
  clip and the enforcer test diverge and one of them is lying. Name the shared path in

  check` will really have — inherited constraints, `alternatives[].why_not`,

`depends_on` as E0 honestly rather than assuming it is present.
