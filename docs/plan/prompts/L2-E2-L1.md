## Context

**Epic:** E2 — Capture (roadmap M2). **Lane:** E2-L1.

`dira sniff` is capture tier 1: pure pattern matching over a Claude Code transcript,
run from the `Stop` hook after every turn. It is cheap, offline, deterministic, and
lossy. Everything it produces is `state: staged` + `source.tier: regex` and waits for a
human — because a regex has no business asserting rationale (`dec-0003`). It is the
lane that makes the epic's first L0 clause true: *"a recorded transcript fixture
containing decision language yields ≥1 staged entry and zero accepted entries."*

**Lane `acc:` verbatim:**

> `go test ./internal/sniff` passes against `testdata/transcripts/` holding ≥3 recorded
> Claude Code transcripts, asserting on the entries actually written to a temp ledger:
> every entry has `state: staged`, `source.tier: regex`, `source.hook: Stop`, and a
> non-empty bounded `source.excerpt`; **zero** entries are in `accepted`, `active`, or
> `open`; **zero** entries carry a non-empty `alternatives[]` or any `why_not`; every
> written file validates against `schema/entry.schema.json`; and a fixture with no
> decision language writes no file and, under `--quiet`, prints nothing and exits 0.

**depends_on:** `E0-L1` (Go module and command skeleton), `E0-L2` (the schema validator
and its `internal/ledger/testdata/invalid/` fixtures), `E1-L1` (storage interface and

### E2-L1-T1 — Resolve and record the two staged-entry schema conflicts

`docs/plan/lanes/E2.md` names both. Restated so this task is self-contained:

1. **`state: staged` is legal only on `kind: decision`.** The schema's `allOf` gives
   `question` the enum `open | answered`. But `docs/design/screens/s3-distill.html`
   shows a staged `qst-0006` in the distill queue, and writing a regex-inferred question
   directly as `open` makes the ledger assert an open question no human ever saw —
   which then feeds `dira brief` and, later, decision-blocked detection (`dec-0004`).
   **Recommendation:** add `staged` to the `question` state enum. `state: staged` +
   `source.tier: regex` is precisely the "not yet trusted" marker, and `dec-0003`'s
   reason for staging (a regex may not assert rationale) applies to a question's
   framing as much as to a decision's why_not.
   **Honest fallback if that is rejected:** `sniff` stages `decision` only, and
   question capture is deferred to the semantic tier (E2-L2) where a human-facing
   session frames it. Say which you chose and why.
2. **`kind: decision` requires `alternatives`, yet a regex may not assert a
   `why_not`.** `alternatives: []` passes the schema (there is no `minItems`) while
   contradicting the schema's own stated intent: *"a decision without alternatives is
   an assertion, not a decision."* **Recommendation:** make it conditional —
   `minItems: 1` on `alternatives` unless `state: staged` — so the intent is enforced
   for every citable decision and an empty array is legal exactly where it is honest.

`files:` `.dira/entries/dec-00NN.md` (new), `schema/entry.schema.json` (only if the
resolution changes it).

`acc:` a new entry exists under `.dira/entries/` recording the resolution of **both**
conflicts, validating against `schema/entry.schema.json`, carrying ≥1
`alternatives[].why_not` for each rejected option and a `derives_from` edge to
`dec-0003`; and if the resolution amends `schema/entry.schema.json`, E0's
schema-validation test passes on the amended schema **and** a new fixture that violates
each newly-added rule (a non-staged decision with `alternatives: []`, a staged question
under the fallback) makes that test fail.

### E2-L1-T2 — Record the transcript fixture corpus, including deliberate near-misses

The fixtures are the lane's evidence, so they must be real transcript shapes, not
hand-written prose. Capture them from actual Claude Code sessions in this repository
(`~/.claude/projects/<slug>/*.jsonl`) and redact anything personal — treat this repo as
public, per the global rules.

Three at minimum: one short session with unambiguous decision language, one long
multi-turn session with several decisions and at least one reversal, and one **negative**
fixture. The negative one is the load-bearing fixture: it must contain deliberate
near-misses — *"we could go with X"*, *"suppose we don't do Y"*, *"what if we picked
Z"*, *"kazi decided to use Burrito"* (someone else's decision), *"let's go with the
example from the docs"* (not a decision about this project) — at least five of them.

`files:` `internal/sniff/testdata/transcripts/short-decision.jsonl`,
`long-session.jsonl`, `near-miss.jsonl`, `internal/sniff/testdata/README.md`.

`acc:` `go test ./internal/sniff -run TestFixtureCorpus` passes: each fixture parses as
line-delimited JSON with the Claude Code transcript envelope, the corpus contains ≥3
files, `near-miss.jsonl` contains ≥5 distinct near-miss phrases enumerated in the test
table, and no fixture contains a home directory path, an email address, or a private
hostname (asserted by pattern, not by review).

### E2-L1-T3 — Read the hook payload and the transcript, failing open on anything missing

A `Stop` hook receives a JSON payload on stdin carrying the session id and the
transcript path. Every failure in this path — no stdin, malformed stdin, absent
`transcript_path`, unreadable file, a truncated final line — must produce **exit 0 and
no output**, because the hook runs in the latency path of a human waiting for a prompt
and `dec-0003`/`int-0002` make dira's presence unnoticeable or nothing.

`files:` `internal/sniff/transcript.go`, `internal/sniff/transcript_test.go`.

`acc:` `go test ./internal/sniff -run TestTranscriptRead` passes with a table covering
at least: absent stdin, `{}`, malformed JSON, `transcript_path` pointing at a
nonexistent file, a file with a truncated final JSON line, and a valid payload. Every
failing case returns no entries, no error to the caller's exit path, and writes nothing
to stderr or stdout; the valid case returns the turn count the fixture actually
contains. No case panics — the test fails on a recovered panic.

### E2-L1-T4 — Build the decision-language matcher with bounded excerpts

Pattern-match decision language over the transcript turns and emit candidates with the
kind, a title, and the excerpt the inference came from. `source.excerpt` is capped at
1000 characters by the schema and is *evidence for review, not a transcript archive* —
so bound it well below the cap and centre it on the matched span.

Precision beats recall here: a false positive costs a human a keystroke and erodes the
distill queue into a chore (`int-0001`), while a false negative is recovered by the
semantic tier at `PreCompact` (E2-L2). Tune to the negative fixture.

`files:` `internal/sniff/matcher.go`, `internal/sniff/patterns.go`,
`internal/sniff/matcher_test.go`.

`acc:` `go test ./internal/sniff -run TestMatcher` passes a table where every phrase in
`near-miss.jsonl` yields zero candidates and every intended decision in
`short-decision.jsonl` and `long-session.jsonl` yields exactly one candidate with a
title ≤120 characters and no trailing period (the schema's `title` rule), and every
emitted excerpt is non-empty, ≤400 characters, and is a literal substring of the
transcript turn it came from.

### E2-L1-T5 — Write staged entries through E1's writer, never a private one

Turn candidates into files. Per `dec-0002` each candidate is one file write; per

### E2-L1-T6 — Make re-sniffing idempotent — `Stop` fires every turn

`Stop` fires after **every** turn and the transcript is cumulative, so a naive `sniff`
restages the same decision on every turn of a four-hour session and the distill queue
fills with duplicates of one decision. Two runs over the same transcript must produce
the same ledger.

`files:` `internal/sniff/dedupe.go`, `internal/sniff/dedupe_test.go`.

`acc:` `go test ./internal/sniff -run TestIdempotent` passes: running the full sniff
twice over `long-session.jsonl` against the same temp ledger leaves exactly the same
set of entry ids and byte-identical files as one run; running it over a transcript
extended by one new turn containing one new decision adds exactly one entry and
modifies none; and a decision whose staged entry a human has already dispositioned (no
longer `staged`) is **not** restaged.

### E2-L1-T7 — Wire `dira sniff --stage --quiet` and pin its exit behaviour

The command line is fixed by `hooks/settings.example.json`:
`dira sniff --stage --quiet 2>/dev/null || true` with a 10-second timeout. `--quiet`
prints nothing when nothing was staged, so the common case adds no noise to the
transcript; without `--quiet` it prints the one-line-per-entry form from
`docs/design.md` §5. Match `.agents/product-marketing.md` §10 for wording: no
exclamation, no "successfully", name the ids.

`files:` `cmd/dira/sniff.go`, `cmd/dira/sniff_test.go`.

`acc:` `go test ./cmd/dira -run TestSniffCommand` passes: `dira sniff --stage --quiet`
over `near-miss.jsonl` exits 0 with completely empty stdout and stderr; over
`short-decision.jsonl` it exits 0, writes the entry, and (without `--quiet`) prints one
line per staged entry naming the id and title; an unknown flag exits non-zero with a
usage line; the command completes over `long-session.jsonl` in under 2 seconds
(comfortably inside the hook's 10s budget) measured by the test; and a test asserts the
process makes no network dial (`cst-0004`) by failing if any package under
`internal/sniff` imports `net/http` or `net`.
