## The three absolutes

1. **Nothing outward-facing is published by an agent.** This lane produces static HTML in
   the repo. **Deploying it is the maintainer's action, not a task here** — no task may
   push to a host, register a domain, or configure DNS.
2. **No virality claims**, and no hype lexicon: never "revolutionary", "seamless",
   "supercharge", "10x", "AI-powered" (§10).
3. **The page may not claim installable software exists.** There is no binary and
   `brew install kazi-org/tap/dira` fails today. The page carries the same design-phase
   status line the README does, and the coherence gate must fail if the page shows a
   working install command while that line is still true. A vaporware install line is a
   direct hit on the one audience that checks.
