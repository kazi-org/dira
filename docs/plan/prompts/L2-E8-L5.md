## The absolutes — this lane is where they are enforced

1. **Nothing outward-facing is ever sent, posted, published, or submitted by an agent.**
   Every marketplace listing, awesome-list PR, and directory submission is a **draft file**
   under `docs/growth/drafts/` awaiting the maintainer. `check-drafts.mjs` is the
   mechanical form of this rule for the whole epic, so it must be strict rather than
   advisory, and it must be red on a bad fixture rather than merely green on good input.
2. **No virality claims**, and none of §10's banned hype lexicon in any listing copy.
3. **The listing may not describe software that does not exist.** No binary has shipped.
   Any listing draft must state the real status, and a task must gate publication on E0's
   release actually existing — not on its plan.

  matching `hooks/` name-for-name, and the skill entry E2 fills in. Version pinning follows
  kazi's contract — the bundle is cut from a binary release, never published independently.

  description each list's format requires, and each list's contribution rules read and
  recorded. A PR that violates a list's format is a rejection *and* a reputation cost.
- `docs/growth/drafts/directory-submissions.md` — the dev-tool directories worth the time
  (dofollow, dev audience), each with its submission requirements. Per `/distribution`,
  Product Hunt is a poor fit for a CLI with no binary; say so rather than listing it out of
  habit.
- `docs/growth/scripts/check-drafts.mjs` — zero third-party dependencies, two-sided, plus
  the deliberately-bad fixtures it must reject.
- A frontmatter contract for drafts, documented in one place, so every other lane's drafts
  (E8-L6's HN post, the Reddit post, the X thread) validate under the same checker.

**The two collisions to name, not resolve silently:**

- **Ownership.** E2 owns the skill's content and `dira install-hooks`. This lane owns
  packaging and listing. If E2's lane also writes `.claude-plugin/plugin.json`, one of them
  silently wins and the loser's work is lost. Name the file and the boundary in your output
  so the lead can assign one owner.
- **Versioning.** If the marketplace bundle ships on its own cadence, plugin content lags
  the binary and users get a skill that references flags the installed binary lacks. kazi
  already hit and solved this; copy the solution.
