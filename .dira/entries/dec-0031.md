dira needs a public artifact a stranger can land on (dec-0010, note-0001's stranger path) without contradicting the static-output, no-hosted-tier constraint (dec-0012). kazi already solved this exact problem for kazi.sire.run: Astro + Tailwind static build, GitHub Pages via public/CNAME, a README <-> site coherence gate so the two surfaces cannot drift, and Playwright smoke tests gating every PR. docs/plan/website.md scopes the mirror: the site consumes dira's own `dira ui` output for its centerpiece (the /why pages, snapshotting dec-0001) rather than reimplementing a renderer, and the deploy job stays workflow_dispatch-only behind a pages-live environment until the founder wires DNS and activates it (docs/growth/site-activation.md).
