dira embeds subsetted **TeX Gyre Pagella** — regular, italic and bold — and stops
relying on a font stack that resolves differently per platform.

## Why this is a correctness fix, not a taste preference

`dec-0012` established that the UI is server-rendered and embedded in a Go binary that
must work offline, and the reasoning recorded at the time was that webfonts "bloat the
binary for zero functional gain." **That trade was miscounted.** The gain is
cross-platform typographic determinism, which is exactly what the system-font rule
existed to buy and was not delivering. `embed.FS` puts the subset inside the binary with
no network call, so the offline guarantee is untouched. Total payload: 60.6 KB for three
faces.

## Why Pagella specifically

It is a **Palatino metric clone**, so every measure, leading and scale value already
tuned in this system stays valid — self-hosting became a pure determinism fix with zero
re-tuning. It was also the **only candidate with complete glyph coverage** for the
characters this design uses, and the smallest subsetted payload of the five tested.

## Licence obligations, met

GUST Font Licence (LPPL 1.3c). Renaming a derived work is *requested, not required* —
GUST says so explicitly — and these files keep the Pagella name with outlines unaltered.
LPPL 6b requires prominent notice of the nature of any change: these are **subsets**,
recorded in `NOTICE` and `assets/fonts/README.md`.

## What this does not change

The fallback chain stays in place behind the embedded face, so a build that somehow
ships without the font still renders. `dec-0012`'s server-rendered, no-SPA architecture
is untouched — this narrows only the "no webfont" reading of the offline constraint.

## The reason this was found at all

Not by the design gates. A critic briefed to argue the direction should be reopened
found it while building a case it ultimately conceded, and it is the third gate this
session shown blind to what it appeared to guarantee — the coverage checker could not
see its own untracked source, the contrast matrix could not see a composited tint, and
the render harness cannot see a font fallback it will never experience. Same shape each
time: the check validates the declaration rather than the rendered result.
