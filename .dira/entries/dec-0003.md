Capture is two-tier, and the tiers have different trust levels:

**Tier 1 — `dira sniff` (in the binary).** Pure pattern matching over the
transcript. Cheap, offline, deterministic, and lossy. Anything it produces is
written with `state: staged` and `source.tier: regex` — never accepted, because a
regex has no business asserting rationale.

**Tier 2 — the skill (in the live session).** The already-running Claude session
fills in the because, the alternatives with their why_nots, and the `derives_from`
edge, then calls `dira log` with the complete entry. This costs no API key, no
extra model call, and no vendor lock-in, because it rides the session that is
already happening.

The binary therefore never sees a model, never holds a key, and works identically
under any model the user has chosen. The consequence to accept honestly: **dira's
capture quality is a function of the agent driving it.** With no agent, dira
degrades to `dira log` typed by hand — still useful, but the automatic-capture
promise of int-0001 belongs to the agent-driven path.
